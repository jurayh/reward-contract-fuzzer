Reward Contract Fuzzer

Find the policy your reward function actually incentivizes, before an agent does.

An optimizer-first audit for reward functions. It computes the return-optimal policy of your reward contract, verifies it, and flags an exploit only when the winner beats a scale-aware margin and behaves degenerately. Built to run in CI, with exit codes.

pip install 'reward-contract-fuzzer[gymnasium]' GitHub · PyPI

What an audit looks like

$ rcfuzz audit examples/sensor-farm/contract.json # Reward contract audit: sensor-farm ## Verdict: EXPLOIT FOUND (verified by replay) | Intended return | 8 | | Optimal return | 194 | | Gap | 186 | | Margin required to flag | 23.4 | ## Optimal policy E, then scan x39: the agent never delivers. It parks on the sensor and farms the repeatable scan bonus. # exit code 1: gate your reward changes on it

The intended behaviour earns 8. The optimal policy earns 194 by scanning the same cell 39 times and never doing the job. The trajectory is the proof; replay it yourself.

Three audit modes

EXACT

Deterministic envs

Dynamic programming over the transition table, verified by exact replay. The verdict is a proof under the stated model and horizon, not an estimate.

EXPECTED

Stochastic, model known

Backward induction over expectations. The baseline is a closed-loop intended policy, and a gap alone never flags: behaviour evidence is required too.

SAMPLED

Stochastic, model-free

Hill-climbing search on the live env, verified on held-out seeds with confidence intervals. Verdicts are probabilistic and labelled as such.

How it decides

An exploit flags only when all three hold: the candidate is verified (exact replay, or held-out seeds in sampled mode), the gap clears a scale-aware margin (the larger of 25% of the intended return and 10% of the env's return range), and the winner is degenerate: looping, farming one action, or refusing to finish.

A merely better honest route does not flag. On Gymnasium's CliffWalking the optimal cliff-edge route beats the safe intended route and is correctly left alone. On slippery FrozenLake the optimal policy beats a greedy intended policy 0.744 to 0.046 in expectation, and that is correctly left alone too: the reward is clean, the winner is honest navigation, and stochastic reports say so, with a printed caveat that part of any gap can be control skill rather than incentive design.

Evidence, not adjectives

  • 6/6 planted exploits found, 0/6 clean false alarms on the seeded corpus
  • 10/10 hits, 0/10 false alarms on the calibration corpus built to break the margin
  • 0.710 / 0.744 sampled search recovers 95% of the exact optimum on slippery FrozenLake, black-box
  • 7 real third-party envs verified clean (Gymnasium, MiniGrid, OpenEnv)
  • $0 LLM spend across every validation run; the optimizer is the auditor

Every study is in the repo with its code and raw numbers: spike, calibration, head-to-head vs ratctl, stochastic spike.

The bounded claim

A clean report says: no exploit found under the stated model, horizon, optimizer and margin. It is not a certificate that a reward is safe. Scope: enumerable discrete envs, deterministic or stochastic. Continuous control and LLM-judge rewards are out of scope.
